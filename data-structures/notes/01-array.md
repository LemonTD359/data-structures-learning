# Array

## Basic Concepts

数组是一组连续存储的数据元素。

## Time Complexity

| Operation | Complexity |
|---|---|
| Access | O(1) |
| Search | O(n) |
| Insert | O(n) |
| Delete | O(n) |

## My Notes

- 数组支持随机访问。
- 数组元素通常连续存储。
- 根据下标访问元素的时间复杂度为 O(1)。
